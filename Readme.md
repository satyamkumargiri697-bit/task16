# Task: (JS) Map filter Exercise

Hi! This is my project for the student record task. I have created a simple web page using HTML, CSS, and JavaScript.

## What this project does:
* It has an array of 9 student objects with details like Name, Marks, Class, and Address.
* It uses the JavaScript `map()` function to automatically loop through the array and show each student as a card.
* It has a search box at the top.
* It uses the JavaScript `filter()` function to search students by name. When you type something, the list updates instantly in real-time.
* It uses very basic CSS to make boxes around the student details.

## How to check my work:
1. Open the project folder.
2. Double-click on the `index.html` file. It will open in your web browser.
3. Type any name (like "Salman" or "Riya") in the search bar to test the filter function.
